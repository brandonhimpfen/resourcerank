# Changelog

## 1.1.0

Includes:

- Added data/evaluations.jsonl containing real-world resource evaluation cases.
- Added a formal JSON Schema for evaluation records.
- Added dataset documentation and provenance guidance.
- Added validation tooling for evaluation records.
- Introduced explicit signals for category fit, maturity, independent adoption, recognition, affiliation, cross-list submissions and decision outcomes.
- Distinguished historical curation decisions from permanent judgments about resources.
- Established ResourceRank as the resource-evaluation framework referenced by the broader Awesome Lists ecosystem.

## 1.0.0

Initial release of ResourceRank.

Includes:

- CLI-based resource evaluation
- Structured JSON review output
- Configurable review profiles
- Awesome List, newsletter source, and dataset catalog profiles
- Example inputs
- End-user documentation
- GitHub Actions starter workflow
- Basic test coverage
